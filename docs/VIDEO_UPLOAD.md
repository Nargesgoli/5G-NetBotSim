# Add experiment videos

The recordings are being uploaded separately by the authors.

1. Open the appropriate experiment folder on GitHub and choose **Add file → Upload files**.
2. Upload the human-to-robot recording under `experiments/human_to_robot/`, and the robot-to-robot recording under `experiments/robot_to_robot/`.
3. Open each uploaded file, copy its GitHub URL, and add a **Watch experiment video** link to the experiment README and the main README. Replace the pending-upload text once the links work.

For a recording too large for the browser uploader, host it in a GitHub release or an accessible video service and add that URL instead. Check that visitors can open the link without signing in.

Use the original experiment recordings. H.264 video with AAC audio in an MP4 container is suitable for broad playback compatibility.
