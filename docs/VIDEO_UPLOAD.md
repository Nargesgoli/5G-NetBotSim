## Viewing

GitHub may display “we can't show files that are this big right now” on the file page. This is a preview limitation; the file remains available through **View raw**. The links above point directly to the raw files. Browsers may play or download them. If playback is unavailable, download the file and open it in a local media player such as VLC.

These links provide file access rather than an embedded player in the README. For an inline viewing experience, upload the recording to a video-hosting service and replace the links with its viewing URLs.

## Updating a recording

Replace the existing file at the same path to keep the README links valid. If you rename or move a file, update its links in the main README, the corresponding experiment README, and this page. File names are case-sensitive.

Keep the original experiment content. For a smaller browser-compatible copy, export MP4 with H.264 video and AAC audio, then upload that copy and update the links. Preserve the original recording separately.
