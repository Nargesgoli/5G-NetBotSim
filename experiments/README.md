# Experiments

The two groups follow Section IV-C of the paper:

1. [Human-to-robot teleoperation](human_to_robot/): robotic-arm position/waypoint and velocity-parameterized commands.
2. [Robot-to-robot leader–follower coordination](robot_to_robot/): two quadrotors exchanging leader state through UE1 and UE2.

Network conditions, timing, and processing overhead are evaluated within these workflows.
