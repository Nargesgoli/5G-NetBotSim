# Licensing status

This initial mixed-origin research release has no blanket repository-wide license. Existing source headers, SPDX identifiers, and dependency-specific terms remain applicable. The GNU Radio broker identifies GPL-3.0; its license text is included under `LICENSES/`.

The authors should select an explicit license for their original additions before advertising general open-source reuse rights. Public availability alone does not grant reuse permission for otherwise unlicensed files. See `THIRD_PARTY.md` for attribution.
